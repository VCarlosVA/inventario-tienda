# Sistema de Control de Inventario para Tienda de Barrio

Aplicación web para gestionar productos, categorías, proveedores y movimientos
de stock, con reportes, estadísticas y autenticación segura con roles.

**Autor:** Carlos Vicente Vargas Arcaya
**Plataforma:** CV-INFORMATICA

## Stack
- Frontend: React
- Backend: NestJS + TypeORM + PostgreSQL
- Documentación API: Swagger
- Despliegue: Docker, Kubernetes
